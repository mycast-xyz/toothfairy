## 추가 QA (테스트 중 발견)

| 심각도 | 발견 | 상세 |
|---|---|---|
| ✅ 정상 | **선결제 남은금액** | 청구서 상세에서 0→22,000 입력 시 청구금액 **122,000 → 100,000**(정확히 22,000 차감). 정상 작동 |
| ✅ 수정됨 | **배송비 미반영** | (발견) 배송비를 바꿔도 청구금액 불변. **원인**: `updateDeliveryInvoice`가 `corpInfo.deliveryInvoice` 갱신 전에 `deliveryInvoice.set()`을 호출 → `totalPrice`(derived)가 옛 배송비로 동기 재계산. **수정**: corpInfo 먼저 갱신 후 set. **검증**: 배송비 50,000→70,000 시 출력금액 **122,000 → 142,000**(정확히 +20,000). `InvoiceViewStore.ts` |
| 🟡 표시오류 | **파일 개수 "0개"** | show 상세 "노멀 파일 정보 \| 0개"인데 실제 "선택됨: 2개"·"파일: 2개"·뷰어 2개. 개수 표시가 0으로 잘못 나옴 (Phase B 범위 밖, 별도 수정 대상) |

> 배송비는 발견 즉시 수정(반응성 순서 버그). 파일개수는 별도 수정 대상.
> 청구 금액 계산 자체(종류별 단가)는 **C2로 보류**(파일기반 도메인 결정과 연계).
